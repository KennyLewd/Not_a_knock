# T09 — Menu bar, onboarding, and background behavior

## Objective

Make the utility behave like a finished menu bar Mac app.

## Acceptance criteria

- Menu bar controls expose listening state, pause/resume, open window, and quit.
- Closing the main window keeps the utility running when configured.
- First-run onboarding explains modes, permissions, calibration, and test knocks.
- Launch at Login uses the supported ServiceManagement API.
- Relaunch restores a coherent listening state without surprise permission prompts.
