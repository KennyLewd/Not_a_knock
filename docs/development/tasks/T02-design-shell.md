# T02 — App shell and design system

## Objective

Create the polished, native visual foundation: window behavior, sidebar, typography, colors, cards, buttons, spacing, hover states, and reusable components.

## Acceptance criteria

- Dashboard, Activity, and Settings navigation works.
- Layout remains usable at the minimum and default window sizes.
- Pattern gradients and all neutral surfaces are defined centrally.
- Keyboard focus and reduced-motion behavior are deliberate.
- Light accidental regressions are checked with app screenshots at two window sizes.
