# T10 — QA, accessibility, performance, and packaging

## Objective

Produce a release-candidate app and a documented distribution path.

## Acceptance criteria

- Clean build and focused unit/UI tests pass.
- VoiceOver, keyboard navigation, Reduce Motion, and contrast are checked.
- Idle CPU, memory, and microphone processing are measured and acceptable.
- Permission and hardware-failure paths are manually verified.
- App icon, versioning, archive settings, signing requirements, and direct-distribution/notarization steps are documented.
- A release checklist and known limitations are included.
